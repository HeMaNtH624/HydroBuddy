The Problem

Plants Die When
Nobody's Watching

Hydroponic systems demand constant vigilance — a slight deviation in pH or nutrients can wipe out an entire crop in hours.

⏱️

24/7 Manual Monitoring

pH, TDS, temperature and humidity need constant checking — impractical for most growers

📉

Parameter Drift

Small deviations compound — a pH of 7.5 left unchecked for hours causes root damage and crop loss

🌍

No Remote Access

Traditional systems give no visibility or control unless you're physically present

✅ HydroBuddy solves this by...

  • Continuously monitoring all 5 parameters every 2 seconds
  • Automatically triggering pumps, fans and lights when thresholds are crossed
  • Loading optimal thresholds per crop from a cloud database
  • Uploading live data to Supabase every 10 seconds for remote monitoring
  • Providing a real-time web dashboard accessible from any device
  • Applying temperature compensation to TDS readings for accuracy

Hardware

Sensors &
Actuators

Every component chosen for reliability and precision. From biomedical-grade sensors to transistor-driven relay control — the hardware layer leaves nothing to chance.

🌡️
Air Temperature & Humidity
DHT11 · GPIO 4

Reads ambient air temperature and relative humidity. Uses isnan() validation to detect failed readings and default safely to 0.0.

💧
Water Temperature
DS18B20 · OneWire · GPIO 22

Waterproof digital temperature sensor. Must be read before TDS — its value is used in the compensation formula.

🧪
pH Level
Analog BNC · GPIO 32

10-sample averaging reduces analog noise. Voltage converted to pH using 3.5× factor plus calibration offset.

⚗️
TDS / Nutrients
Analog EC · GPIO 34

Measures dissolved nutrient concentration in ppm. Temperature-compensated using cubic polynomial conversion formula.

🔌
Relay Control
BC547 Transistor · GPIO 17/19

BC547 transistors drive 5V relay modules. HIGH signal activates transistor base, energizing the relay coil.

📶
WiFi Connectivity
ESP32 Built-in · 2.4GHz

Station mode WiFi with DHCP. Auto-reconnect watchdog in main loop. HTTP POST to Supabase every 10 seconds.

Core Logic

Firmware Deep Dive

Written in Arduino C++ — every function designed for reliability in a 24/7 unattended environment.

tds_compensation.cpp
// Temperature compensation for TDS // Water conducts more electricity at // higher temps → false high readings float readTDSSensor() { int raw = analogRead(TDS_PIN); // 12-bit ADC: 0-4095 → voltage float voltage = raw * (5.0 / 4095.0); // Normalize to 25°C reference // 2% change per degree Celsius float comp = 1.0 + 0.02 * (waterTemp - 25.0); float compV = voltage / comp; // Cubic polynomial → ppm return (133.42*pow(compV,3) - 255.86*pow(compV,2) + 857.39*compV) * 0.5; }
non_blocking_loop.cpp
// millis() → no blocking, server stays live unsigned long lastRead = 0; unsigned long lastCtrl = 0; unsigned long lastUpload = 0; void loop() { server.handleClient(); // always first unsigned long now = millis(); // Every 2s → read sensors if (now - lastRead >= 2000) { lastRead = now; readSensors(); } // Every 10s → control logic if (now - lastCtrl >= 10000) { lastCtrl = now; checkAndControl(); } // Every 10s → cloud upload if (now - lastUpload >= 10000) { lastUpload = now; sendSensorData(); } }
control_logic.cpp
// Threshold-based actuator control void checkAndControl() { if (!isCropConfigured()) return; // Air temp → cooling fan if (airTemp > cropConfig.max_air_temp) digitalWrite(FAN_PIN, HIGH); else digitalWrite(FAN_PIN, LOW); // Water temp → cooling pump if (waterTemp > cropConfig.max_water_temp) digitalWrite(PUMP_PIN, HIGH); else digitalWrite(PUMP_PIN, LOW); // pH and TDS → log warnings if (pHValue > cropConfig.max_ph) Serial.println("pH out of range!"); }
ph_sampling.cpp
// 10-sample averaging reduces noise // Analog sensors fluctuate per read float readPHSensor() { float sum = 0; // Collect 10 samples 10ms apart for (int i = 0; i < 10; i++) { sum += analogRead(PH_PIN); delay(10); } // Average → voltage (3.3V, 12-bit) float voltage = (sum/10) * (3.3 / 4095.0); // Voltage → pH + calibration return 3.5 * voltage + phCalibration; }
